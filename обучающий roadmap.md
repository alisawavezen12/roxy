# Обучающий roadmap

## Frontend

- [ ] **Lustre**
  - [ ] Model / Message / Update / View
  - [ ] состояние приложения
  - [ ] обработка событий и DOM
  - [ ] HTTP-запросы
  - [ ] роутинг

- [ ] **Gleam → JavaScript**
  - [ ] компиляция проекта в JavaScript
  - [ ] вызов JavaScript-функций из Gleam
  - [ ] передача данных между Gleam и JavaScript
  - [ ] сборка frontend для production

- [ ] **WebAssembly на Rust**
  - [ ] написать небольшую функцию на Rust
  - [ ] скомпилировать её в WASM
  - [ ] вызвать WASM из frontend
  - [ ] выбрать отдельную CPU-intensive задачу

## Backend

- [ ] **Wisp**
  - [ ] структура web-приложения
  - [ ] роутинг и HTTP-обработчики
  - [ ] JSON-запросы и ответы
  - [ ] middleware
  - [ ] обработка ошибок

- [ ] **Mist**
  - [ ] запустить HTTP-сервер
  - [ ] понять связь Mist и Wisp
  - [ ] настроить сервер
  - [ ] подключить WebSocket

- [ ] **BEAM / OTP**
  - [ ] процессы и обмен сообщениями
  - [ ] actors в Gleam
  - [ ] supervisors и стратегии перезапуска
  - [ ] фоновые задачи
  - [ ] graceful shutdown

- [ ] **PostgreSQL**
  - [ ] спроектировать таблицы и связи
  - [ ] миграции
  - [ ] индексы и транзакции
  - [ ] pagination
  - [ ] `EXPLAIN` и планы запросов

- [ ] **pog**
  - [ ] подключить PostgreSQL к Gleam
  - [ ] выполнять параметризованные запросы
  - [ ] работать с результатами запросов
  - [ ] обрабатывать ошибки базы данных

## Realtime и интеграции

- [ ] **WebSocket**
  - [ ] подключение и отключение клиента
  - [ ] переподключение
  - [ ] синхронизация состояния доски
  - [ ] создание, перемещение, изменение размера и удаление объектов
  - [ ] проверка прав доступа

- [ ] **Бинарный протокол**
  - [ ] определить формат сообщения
  - [ ] добавить тип, версию и идентификатор сообщения
  - [ ] реализовать сообщения для событий доски
  - [ ] обрабатывать неизвестные версии и типы
  - [ ] сравнить размер и скорость с JSON

- [ ] **Webhooks**
  - [ ] входящий webhook: secret и валидация payload
  - [ ] преобразование входящего события в пост
  - [ ] исходящий webhook: отправка события пользователю
  - [ ] background job и retry при ошибке
  - [ ] история попыток доставки
